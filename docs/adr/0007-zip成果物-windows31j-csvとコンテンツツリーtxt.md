# ADR 0007: zip成果物(Windows-31J csv + コンテンツツリーtxt)

- Status: Accepted(現状追認 — 2026-07-04 にコードから逆起こし)
- 関連: [ADR 0004](0004-集計照合クエリの生SQL実装.md), [specs/07-credit-download.md](../specs/07-credit-download.md)

## Context

本サービスの最終成果物は「動画で使用したモデル・アクセの一覧表」である。
利用者はこれを動画説明文のクレジット表記と、ニコニコ動画のコンテンツツリー登録に使う。
利用者の環境はWindows + Excelが主流(MMD自体がWindows専用ツール)。

## Decision

`/videos/:id/zip` で以下2ファイルを含むzipを動的生成して返す
(`app/models/video.rb#create_dl_zip`):

1. **`credit.csv`** — クレジット一覧表
   - 文字コードは **Windows-31J**(ExcelでダブルクリックしてもEncodingが崩れない為と推定)
   - ヘッダ: `名前,作者,配布先,拡張子,ステータス`
   - 先頭に `musts` テーブルの定番項目(MMD本体・ミクモデル等と推定)を「ステータス○」で出力。
     動画のemm拡張子に応じてカテゴリを選ぶ(`.xml`/`.mpj` を含めば `mmm`、それ以外は `mmd`、`all` は常時)
   - 以降は動画で使用したオブジェクト(credit有=○ / 無=×、無い場合の名前は `file_name` で代用)
2. **`tree.txt`** — コンテンツツリー登録支援用
   - musts の `video`(登録済み作品ID)+ 各creditの `distribution`(sm/im/td等のニコニコID、空を除く)
   - **10個ごとに空白区切りで1行**にする(ニコニコのツリー登録フォームが一度に受け付ける
     件数に合わせたものと推定)
3. 生成は `Rails.root/tmp` に一時ファイルを作り、zip化後にcsv/txtを削除する。
   zipファイル自体は削除されず tmp に残る(経緯不明。掃除処理は見当たらない)。

## Consequences

- 利用者はダウンロードしてそのままExcelで開ける/ツリー登録にコピペできる。
- Windows-31Jに変換できない文字(機種依存文字・絵文字等)がモデル名・作者名にあると
  csv生成が例外になり得る(コード上のレスキューなし)。
- zip一時ファイルが tmp に蓄積し続けるため、ディスクを圧迫する(運用でのクリーンアップ前提)。
- リクエスト同期生成のため、大量オブジェクトの動画ではレスポンスが遅くなる。
